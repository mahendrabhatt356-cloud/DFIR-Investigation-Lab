# 🔎 DFIR Investigation Lab

> A practical Digital Forensics & Incident Response investigation lab built around realistic, fictional cyber incidents.

---

## 🕵️ What is this project?

**DFIR Investigation Lab** is a hands-on cybersecurity project where cyber incidents are investigated from the first alert to the final incident report.

Instead of only learning security concepts theoretically, this project follows the workflow of a real security investigation:

```text
🚨 ALERT
   ↓
🔍 TRIAGE
   ↓
📂 EVIDENCE COLLECTION
   ↓
🕒 TIMELINE ANALYSIS
   ↓
🔎 IOC INVESTIGATION
   ↓
🧩 ATTACK MAPPING
   ↓
📋 FINDINGS
   ↓
🛡️ RESPONSE
   ↓
📄 FINAL REPORT

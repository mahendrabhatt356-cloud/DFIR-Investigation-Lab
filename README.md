# 🌙 Case-001: The Midnight Login

## 🎬 The Story

It was 02:13 AM.

Most employees at **NovaTech Pvt. Ltd.** were offline.

Then the security team received an alert:

> 🚨 An employee account has logged in outside normal working hours.

At first, nothing was certain.

Maybe the employee was working late.

Maybe it was a normal login.

Or maybe someone else was using the account.

The investigation begins here.

---

## 🔎 The Main Question

**Was this a normal login, or does the evidence suggest suspicious activity?**

We will not guess the answer.

We will follow the evidence.

## 🎯 What We Need To Find

During this investigation we will try to answer:

1. Which account was involved?
2. When did the login happen?
3. Was the login outside the user's normal pattern?
4. What other login activity happened around the same time?
5. Are there any suspicious indicators?
6. What does the complete timeline tell us?
7. What should the security team do next?
